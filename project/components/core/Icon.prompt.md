Lucide icon wrapper; the only way to draw an icon in One Link (no emoji, no Unicode glyphs, no other set).

```jsx
<Icon name="triangle-alert" size={16} />
<Icon name="loader-circle" size={20} stroke={1.75} spin />
```

Requires `<script src="https://unpkg.com/lucide@1.39.0/dist/umd/lucide.min.js"></script>`. Use one icon per meaning (see readme → Iconography vocabulary).
