Where a record or form checks one quantity against another (map UX-20). Rows of label and value, the key difference in bold, then the status line: Within tolerance, Within allowance or Beyond tolerance. No explanatory sentence: the rows say it.

```jsx
<ReconcileCard
  rows={[
    { label: 'Loaded', value: '32.000 t' },
    { label: 'Offloaded', value: '31.950 t' },
    { label: 'Difference', value: '0.050 t', strong: true },
    { label: 'Allowance', value: '0.100 t' },
  ]}
  outcome="allowance"
/>
```

`ReconcilePanel` (within, held, block) is kept for the screens built before the map's convention.
